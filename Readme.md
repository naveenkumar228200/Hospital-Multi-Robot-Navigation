# Robust Multi-Robot Mapless Navigation in Dynamic Environments

## Overview

This research project focuses on autonomous multi-robot
navigation in a dynamic hospital environment using ROS 2,
Gazebo, deep learning, and sensor fusion.

## Technologies Used

- ROS 2
- Gazebo Simulator
- Python
- C++
- PyTorch
- PointNet++
- Multi-Head Attention
- Reinforcement Learning

## Research Objectives

1. Mapless autonomous navigation
2. Multi-sensor fusion
3. Human intention inference
4. Trajectory prediction
5. Multi-robot coordination
6. Explainable AI

## System Architecture

Sensor Data
    |
    v
Perception
    |
    v
Attention-Based Sensor Fusion
    |
    v
Intention and Trajectory Prediction
    |
    v
Decision Making
    |
    v
Robot Control
